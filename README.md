## Resources
Our team will utilize the microservices framework. Some useful information about microservices are found in the following link:
https://www.geeksforgeeks.org/system-design/microservices/

We may utilize Flask or Redis for backend/frontend communication.
https://www.geeksforgeeks.org/python/flask-tutorial/ \
https://redis.io/docs/latest/develop/clients/redis-py/

| | \
| └─Microservice_2 \
|    ├─config.py \
|    └─... \
| \
└─README.md \
